Inside a neural network

Three small experiments that show what a neural network actually does, and how it learns. Every network on this page was written from scratch and trained in Python.

By Noah Lindner, master’s student in Robotics, Cognition, Intelligence at TU Munich

1One neuron draws a line

A neuron is a tiny calculation. It takes some numbers, multiplies each one by a weight, adds a bias, and squashes the result into a value between 0 and 1.

Here every point has two numbers: how far across it is (x1) and how far up (x2). The neuron decides between red cross and blue dot, and its boundary is the dashed line. Move the sliders and watch the line turn and shift.

Training does the same thing automatically: measure how wrong the neuron is, nudge each weight a little in the direction that makes the error smaller, and repeat. This is called gradient descent.

2More neurons bend the line

A single neuron can only ever draw a straight line, and most real problems don’t split that neatly. Connect neurons in layers and their straight lines add up to curves.

Pick a pattern and a network, then press Train. Try the spiral with one neuron, then with 8 + 8. In the diagram, every line is a weight: blue is positive, red is negative, thicker is stronger.

3Read my handwriting

Now a real job. This network learned to read handwritten digits from 60,000 examples. It has never seen your handwriting. Draw a digit and follow it through the network.

    What the network sees

    Your drawing, shrunk to 28 × 28 pixels and centred like the training images: 784 numbers between 0 and 1.

    First layer: 64 neurons

    Each square is one neuron, showing its weights: ink on blue pixels excites it, ink on red pixels holds it back. Highlighted squares are firing right now. Tap one to look closer.

    Second layer: 32 neurons

    These combine the first layer’s patterns. The last layer turns them into one score per digit.

    It recognises most of the 10,000 test digits it never saw during training. Drawing with a finger looks different from those scanned pen strokes, so it will sometimes be wrong. The training digits were written in the US: try a 1 with a long upstroke, the way it’s written in Germany.

    How it’s built

    The networks come from a small Python library I wrote for this project, using only NumPy: layers, backpropagation, and the Adam optimiser, without a deep-learning framework. The test suite checks every gradient against a numerical derivative.

    The digit network has about 53,000 weights in three layers (784 → 64 → 32 → 10). It was trained on rotated, slanted, thicker and thinner versions of the training digits, so it copes better with drawings on a phone.

    This page only runs networks that were already trained. Its JavaScript forward pass and image preprocessing are tested against the Python implementation.
